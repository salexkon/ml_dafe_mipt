# Установка окружения

Все, что нужно в первом семестре, ставится один раз и работает до конца
декабря. До занятия 6 включительно видеокарта не нужна: все задачи считаются
на обычном ноутбуке за секунды. С занятия 7 начинаются нейросети. Небольшие
модели обучаются и на процессоре, для остального подойдет бесплатный
[Google Colab](https://colab.research.google.com) с видеокартой.

Если что-то не получилось, приходите на занятие все равно. На первом занятии
на установку заложено время.

## Шаг 1. Python

Нужен Python от 3.11 до 3.13: на 3.14 пока ставятся не все пакеты курса. Проверить:

```bash
python3 --version
```

Если питона нет или он старый:

- **macOS и Linux**: ставится вместе с miniconda, шаг 3
- **Windows**: лучше сначала поставить WSL командой `wsl --install` из PowerShell с правами администратора, дальше все как в Linux. Альтернатива — работать в Docker. Голый Windows тоже заведется, но проблем будет заметно больше

## Шаг 2. Репозиторий

```bash
git clone <адрес репозитория>
cd ml_dafe_mipt
```

## Шаг 3. Окружение

Менеджер окружений на курсе — miniconda. Ставится
с [сайта](https://www.anaconda.com/docs/getting-started/miniconda/main),
дальше:

```bash
conda create -n ml python=3.11 -y
conda activate ml
```

После активации в начале строки терминала появится `(ml)`. Если его нет,
окружение не активировано, и все дальнейшее пойдет мимо.

## Шаг 4. Библиотеки

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

Первый запуск займет несколько минут.

## Шаг 5. Проверка

```bash
python tools/check_env.py
```

Скрипт напечатает версии и скажет, чего не хватает. Обязательные пакеты
должны быть отмечены как `ok`. Те, что «понадобятся позже», на первом
занятии не нужны.

## Шаг 6. Запуск ноутбуков

```bash
jupyter lab
```

Откроется браузер. Дальше `classes/week_01_intro/seminar_01.ipynb`.

Можно работать и в VS Code: поставить расширение Python и Jupyter,
открыть папку курса и выбрать интерпретатор из `.venv`.

## Аккаунт на Hugging Face

Понадобится со второго занятия: оттуда берем данные.

Зарегистрируйтесь на [huggingface.co](https://huggingface.co) и один раз
выполните вход:

```bash
pip install huggingface_hub
hf auth login
```

Токен создается в настройках профиля, в разделе Access Tokens.
Прав на чтение достаточно.

Зачем это нужно. Без входа лимит на скачивание считается на IP-адрес,
а не на человека. Двадцать пять человек с одного вайфая делят его на всех
и упираются в отказ прямо на паре. С аккаунтом лимит ваш личный.

## Если что-то сломалось

**`pip: command not found`** — используйте `python3 -m pip` вместо `pip`.

**`ModuleNotFoundError` при том, что все установлено** — скорее всего,
не активировано виртуальное окружение либо в Jupyter выбрано не то ядро.
В ноутбуке справа сверху проверьте, какой интерпретатор выбран.

**Долгая установка или ошибки сборки** — обновите pip и попробуйте снова.
Если не помогло, приходите с ноутбуком, разберемся на месте.

**macOS: lightgbm или catboost ставятся, но не импортируются.** В ошибке
будет `Library not loaded: @rpath/libomp.dylib`. Это не про питон: пакету
нужна системная библиотека OpenMP, которой на маке нет по умолчанию.
Лечится одной командой:

```bash
brew install libomp
```

Если homebrew не стоит, работает и `conda install -c conda-forge libomp`.
До седьмого занятия это не мешает: `check_env.py` пометит пакет как сломанный
и пойдет дальше.

**Windows и кириллица в пути** — если имя пользователя написано русскими
буквами, часть библиотек может капризничать. Положите репозиторий
в короткий путь без кириллицы, например `C:\ml`.
